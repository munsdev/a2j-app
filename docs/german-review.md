# German copy review

All German text added in v2, for a native speaker to check. The interface uses Sie. Plain, warm, short sentences, no jargon, readable at B1 level. Mark changes directly in this file or in the source files named below.

## 1. Self-assessment items (`public/items.js`)

Most important: the wording changes how people answer. Each item should describe something a person does in everyday life, not only at work, and be easy to answer with the scale.

## 3. Prompts (`public/library.js`, `PL_TEXT.de`)

Shown with an empty profile, so placeholders in square brackets appear. Check that the instructions are clear German an AI chat will follow, and that requested answers come back in German.

### jobsnear

```
Ich suche Arbeit als [job] in der Nähe von [town] (Umkreis etwa 25 km). Hilf mir, gut zu suchen.

1. Nenne 5 bis 8 Berufsbezeichnungen, die Arbeitgeber in Deutschland für diese Arbeit verwenden.
2. Gib mir Suchbegriffe für die Jobbörse der Bundesagentur für Arbeit und für ein oder zwei andere große Jobportale.
3. Nenne die Arten von Arbeitgebern in meiner Gegend, die dafür meist einstellen.
4. Sag mir zwei Dinge, auf die ich in einer Anzeige achten sollte, bevor ich mich bewerbe, passend zu dem, was ich unten schreibe.

Wenn du im Internet suchen kannst, füge Links zu echten, aktuellen Stellen hinzu. Wenn nicht, sag das und erfinde keine.
Halte die ganze Antwort kurz.


```

### courses

```
Ich möchte als [goal] arbeiten. Hilf mir, Weiterbildungen zu finden, die meine Lücken schließen.

1. Sag mir, welche Kurse oder Abschlüsse die wichtigsten Lücken schließen würden, die kürzesten zuerst.
2. Gib mir Suchbegriffe für die Kurssuche mein NOW (mein-now.de) der Bundesagentur für Arbeit.
3. Sag mir, worauf ich achten muss, damit ein Kurs mit Bildungsgutschein bezahlt werden kann (zum Beispiel AZAV-Zulassung), und was meine Beratung sehen will.
4. Weise auf alles hin, was von meinen Deutschkenntnissen abhängt.

Erfinde keine Kursnamen, Anbieter, Termine oder Preise. Wenn du im Internet suchen kannst, verlinke echte Kurse auf mein-now.de oder Anbieterseiten.
Halte es kurz.


```

Beschreibe kurz einen normalen Arbeitstag als [job] in Deutschland:

Wenn du dir bei etwas nicht sicher bist, sag es.

## 4. Known limitations, precisely

- Occupation names come from ESCO German labels and are not edited here; some are long or formal (for example "Lehrkraft für Gestaltendes Spiel Sekundarstufe").
- Prompts `cv`, `careers` and `projects` are the older prompts in `public/i18n.js` and are not listed.
- Legal pages (`impressum.html`, `datenschutz.html`, `credits.html`) were updated in German and should be checked together with this list.
